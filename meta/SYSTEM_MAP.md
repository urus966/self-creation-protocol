## Note for Beginners

The Self-creation system is built on **Presence Space** as the baseline state. This means that doing nothing is always a valid and complete state for the system.

This is structurally supported by the **Selective Consent Protocol (SCP)**, which grants every participant the right to not act, not respond, and not improve. Protocols are layered in a hierarchy (see `docs/protocols/Protocol_Hierarchy.md`) to ensure that human consent and organism autonomy always have a clear path to interaction while preserving these foundational protections.
